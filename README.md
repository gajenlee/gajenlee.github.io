# Gajendra's Portfolio

Personal portfolio and blog, built with Jekyll and hosted on GitHub Pages.

🔗 **Live site:** https://gajenlee.github.io

## About

This site showcases my projects, technical writing, and background as a software developer working on hospitality technology integrations — including Oracle Simphony POS and Oracle OPERA Cloud (OHIP) systems.

## Tech Stack

- Jekyll (static site generator)
- HTML / CSS
- GitHub Pages (hosting)

## Local Development

Clone the repo and run it locally to preview changes before pushing:

```bash
git clone https://github.com/gajenlee/gajenlee.github.io.git
cd gajenlee.github.io
bundle install
bundle exec jekyll serve
```

Then visit `http://localhost:4000` in your browser.
